# LivingForma — 待决产品问题

状态更新：2026-10-03，LF-150。下方原问题表保留作为设计历史，已解决项以此处和 shared/interfaces.md 为准。

已解决并实测：Vite/Fastify同源运行、Google会话/Owner权限、空空间与原子schema演化、11组件/6皮肤、Neon Free严格TLS、Open Library受控工具审批注册复用、Gemini3.5-flash-lite真实规划及持久预算。LF150/QA147有真实证据。仍待完成：媒体生命周期及真实STT/视觉/TTS整合、最终QA、Render账户条款确认与livingforma.tech上线。3D/Snowflake/任意代码执行不属于当前发布。

## 已确认约束

- 产品优先通用 App 生成与持续演化；首轮演示已确定为读书记录 + 习惯打卡。它们是验收示例而非产品边界；任务、签到、投票等仍只是其他可选案例。
- Google OAuth 登录已确定为 MVP 需求；DevOps 负责 provider 配置与 packages/auth 服务端认证模块，Frontend 负责登录/登出 UI，Backend 负责身份映射与空间权限。具体会话实现尚未确定。
- 上线先使用免费额度；**任何收费发生前必须获得用户确认**。Tiger Data 托管 PostgreSQL 是首选候选，Shared Free 的资格与额度待核实；截图中的 0.5 CPU 选项显示收费，尚无已验证创建的实例。主业务数据只设一个事实来源。
- 通用生成只覆盖受限 schema、组件、动作和声明式工具；不运行任意模型生成代码。3D 属于 stretch goal。
- 组件目录持续扩展：变体、emphasis、calendar-grid 和 4–6 套皮肤已进入需求，精确 schema 待定。cover 首版为书名/排版/稳定配色生成的封面感，不承诺真实图片源。
- 只有空间 Owner 有左上角圆圈，点击扩展到中央输入文字/语音；访客只看网站，无需登录浏览，写入时再 Google 登录。不能把所有登录者当管理员。
- Jarvis 语音改站与摄像头观察/播报是明确里程碑；采集由当前设备用户主动开启，Gemini 理解、ElevenLabs 播报，媒体不通过业务 SSE 传播。不是永久可选项。
- 推荐 Vite + React + TypeScript SPA + Node API；LF-100 验证并锁定，不把推荐写成已安装的框架。
