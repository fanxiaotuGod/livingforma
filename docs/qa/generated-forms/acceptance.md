## Limits and replay

The unchanged response and iframe retain `sandbox allow-scripts`, `form-action 'none'`, `connect-src 'none'` and the existing policies. The compatibility layer dispatches a local synthetic SubmitEvent (`isTrusted=false`) after ordinary trusted user activation. Native form navigation, `form.submit()` and programmatic button.click are not made available; the supported explicit programmatic event path is local requestSubmit. No advanced bypass tests or research were added or run.

The original generated source labels lack of tool permission as `Publish required`, including Participant. That message is imprecise for non-Owners, but the host still sends no unauthorized tool request. After saving, its finally block re-enables Save although the completed calculation is cleared; clicking again returns without writing. These are original candidate UX limitations, not evidence of duplicate submissions or widened host permissions. No universal claim about every possible generated form/browser is made.
